# Agent Spec: Ambient Expense Validation Agent

## Overview
An intelligent expense validation and management system built using Google ADK. The agent processes user expenses, classifies them into categories (`necessity` vs `entertainment`/`luxury`), applies automated approval policies, persists expenses in a local SQLite database, and provides comprehensive monthly summary reports with category-wise spending breakdowns and actionable financial advice on saving money and optimizing fund allocation.

## Architecture & Sub-Agents (Multi-Agent System)
1. **`classifier_agent`**:
   - Classifies expense descriptions into broad categories (`necessity`, `entertainment`, `luxury`).
   - Maintains and checks user category preferences when classification is ambiguous (asking for clarification and remembering user decisions).
2. **`evaluator_agent`**:
   - Applies business rules:
     - **`auto_approved`**: Expenses `< $100` categorized as `necessity`.
     - **`needs_review`**: Expenses `>= $100`, or categorized as `entertainment` / `luxury`, or flagged for human review.
3. **`advisor_agent`**:
   - Analyzes category-wise expenditure metrics.
   - Generates personalized insights on potential money-saving opportunities, discretionary spend reduction, and recommendations on how to channel funds effectively.
4. **`root_agent` (Expense Manager Orchestrator)**:
   - Coordinates multi-agent workflow.
   - Interacts with local SQLite database (`data/expenses.db`).
   - Supports logging new expenses, updating existing expenses, and generating monthly summary reports.

## Example Use Cases
1. **Filing a Necessity under $100**:
   - User: "I spent $45 on groceries today."
   - Result: Classified as `necessity`, policy evaluates to `auto_approved`, saved to database.
2. **Filing a Luxury/Entertainment Expense**:
   - User: "Spent $80 on concert tickets."
   - Result: Classified as `entertainment`, policy evaluates to `needs_review`, saved to database.
3. **Filing an Expense >= $100**:
   - User: "Paid $150 for desk chair."
   - Result: Classified as `necessity`, amount is >= $100 so policy evaluates to `needs_review`.
4. **Updating an Expense**:
   - User: "Update expense #3 amount to $60."
   - Result: Updated in DB, re-evaluated against policy rules, marked for review if needed.
5. **Monthly Review Summary & Financial Insights**:
   - User: "Show me all expenses for this month."
   - Result: Lists all expenses filed in current month grouped by status (highlighting `needs_review`), displays category-wise spend breakdown (e.g. Necessities: $450, Entertainment: $220), and provides actionable savings insights and budget allocation advice.

## Tools Required
1. `record_or_update_expense`: CRUD tool for SQLite database (`expenses.db`).
2. `get_monthly_expenses`: Tool to fetch expenses for a given month (`YYYY-MM`), grouped by approval status and category totals.
3. `get_saved_category_preference`: Tool to lookup learned user category rules.
4. `save_category_preference`: Tool to persist user clarification on custom/ambiguous categories.

## Constraints & Safety Rules
- Expenses equal to or greater than $100 **MUST ALWAYS** be set to `needs_review`.
- All entertainment or luxury expenses **MUST ALWAYS** be set to `needs_review`.
- Non-deterministic or ambiguous categories must trigger a clarification prompt to the user and remember their choice.
- Monthly summary reports MUST include category breakdowns and financial optimization insights.

## Data Storage
- Local SQLite database (`ambient-expense-agent/data/expenses.db`).
- Tables:
  - `expenses`: `id`, `description`, `amount`, `category`, `status`, `month` (`YYYY-MM`), `created_at`, `updated_at`.
  - `category_preferences`: `category_name`, `classification` (`necessity` | `entertainment`), `updated_at`.

## Success Criteria
- 100% adherence to approval threshold rules (`< $100` necessity -> `auto_approved`; others -> `needs_review`).
- Successful persistence and retrieval of monthly expense records.
- Support for saving updates to existing expense entries.
- Category-wise spending breakdown and tailored financial advice included in monthly reports.
